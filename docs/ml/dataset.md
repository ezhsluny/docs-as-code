# Data Sheet

## Общая информация

**Название датасета:**  
DataTurks Resume NER (Entity Recognition in Resumes)

**Источник:**  
GitHub-репозиторий DataTurks-Engg:  
[https://github.com/DataTurks-Engg/Entity-Recognition-In-Resumes-SpaCy](https://github.com/DataTurks-Engg/Entity-Recognition-In-Resumes-SpaCy)  
Также доступен на Kaggle:  
[https://www.kaggle.com/datasets/dataturks/resume-entities-for-ner](https://www.kaggle.com/datasets/dataturks/resume-entities-for-ner)

**Назначение:**  
Датасет предназначен для обучения и оценки NER-моделей, извлекающих ключевые сущности из резюме: имя, образование, навыки, предыдущие места работы и т.п.

## Состав данных

**Объём:**  
220 аннотированных резюме.

**Тип данных:**  
Тексты резюме на английском языке с ручной аннотацией в формате JSON (BIO-разметка сущностей).

**Основные поля / признаки:**  
- исходный текст резюме;
- аннотации сущностей (позиции в тексте, тип сущности);
- категории сущностей, соответствующие схеме DataTurks (компании, должности, навыки, образование и др.).

## Получение данных

Резюме были скачаны с онлайн-платформы по трудоустройству, затем загружены в инструмент аннотации DataTurks и размечены вручную.  
Платформа и дата сбора в публичном описании не указаны.

## Предобработка

В исходном описании датасета предобработка явно не детализирована.  
Известно, что данные были приведены к JSON-формату, пригодному для обучения NER-моделей.  
Авторы модели `yashpwr/resume-ner-bert-v2` дополнительно объединяли DataTurks с другими источниками и приводили схемы меток к единому формату из 25 сущностей.

## Ограничения

1. **Язык:** только английский.
2. **Объём:** 220 резюме — относительно небольшой набор для обучения «с нуля».
3. **Домен:** резюме с одной платформы; распределение профессий и форматов может быть смещено.
4. **Потенциальное ограничение для нашего проекта:** датасет не покрывает русскоязычные резюме.

## Использование в проекте

Датасет используется косвенно: он входит в состав обучающих данных выбранной модели `yashpwr/resume-ner-bert-v2`.  
В рамках проекта Resume Analyzer датасет также может использоваться для:

- валидации качества извлечения сущностей на английских резюме;
- потенциального дообучения модели под конкретные форматы резюме;
- формирования тестовой выборки для проверки полей `skills`, `education`, `experience`.
