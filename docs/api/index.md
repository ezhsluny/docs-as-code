# API

API предоставляет доступ к функциям ИИ-сервиса «Анализатор резюме»:
извлечение навыков, образования и опыта из резюме, оценка соответствия
вакансии и ранжирование кандидатов.

## Основные операции

- `POST /resumes/{resumeId}/analyses` — запустить анализ загруженного резюме;
- `GET /analyses/{analysisId}` — получить результат анализа;
- `GET /vacancies/{vacancyId}/candidates` — получить ранжированный список кандидатов.

## Спецификация

Полное описание API находится в файле [`openapi.yaml`](openapi.yaml).

Спецификацию можно открыть и проверить в Swagger Editor:
<https://editor.swagger.io/>.

## Формат ошибок

Ошибки возвращаются в едином формате:

```json
{
  "code": "RESUME_NOT_FOUND",
  "message": "Resume with id 101 not found"
}
```
