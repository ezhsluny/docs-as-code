# Требования

## User Stories

### US-01. Автоматическое извлечение данных из резюме
**Как** HR-специалист / рекрутер,  
**я хочу** загружать резюме и автоматически получать структурированные навыки, образование и опыт,  
**чтобы** быстрее оценивать кандидатов и не тратить время на ручной разбор текста.

**Критерии приёмки:**

- система принимает резюме в поддерживаемых форматах (например, PDF и DOCX)
- после обработки отображаются извлечённые блоки «Навыки», «Образование» и «Опыт работы»
- если текст не удалось распознать или извлечь, пользователь получает понятное сообщение об ошибке

### US-02. Оценка соответствия резюме вакансии
**Как** нанимающий менеджер,  
**я хочу** сравнивать резюме кандидата с требованиями вакансии и получать оценку соответствия,  
**чтобы** быстрее отбирать релевантных кандидатов на собеседование.

**Критерии приёмки:**

- пользователь может выбрать вакансию и резюме для сравнения
- система показывает итоговую оценку соответствия
- если в вакансии не заданы ключевые требования, система сообщает об этом и не формирует некорректную оценку

### US-03. Ранжирование и экспорт кандидатов
**Как** HR-специалист / рекрутер,  
**я хочу** видеть кандидатов, отсортированных по релевантности вакансии, и экспортировать результаты,  
**чтобы** быстро передать шорт-лист нанимающему менеджеру.

**Критерии приёмки:**

- список кандидатов отображается с сортировкой по убыванию оценки релевантности
- пользователь может применить фильтры по навыкам и опыту, и сортировка сохраняется для отфильтрованного списка
- экспорт результатов доступен в согласованном формате (например, CSV) и содержит оценку, ключевые навыки и статус соответствия

## Use Case

### UC-01. Автоматическое извлечение данных из резюме

**Актор:** HR-специалист / рекрутер

**Цель:** получить структурированные данные (навыки, образование, опыт работы) из загруженного резюме

**Предусловие:** пользователь авторизован в системе и загрузил резюме в поддерживаемом формате (PDF/DOCX)

**Основной сценарий:**

1. HR-специалист открывает загруженное резюме и нажимает «Анализировать».
2. Система передаёт текст резюме в ML-пайплайн (NLP/NER).
3. ML-модель извлекает данные: навыки, образование, опыт работы.
4. Система получает результат и нормализует извлечённые данные.
5. HR-специалист видит структурированные блоки «Навыки», «Образование», «Опыт работы» с указанием уверенности модели.

**Альтернативный сценарий:**
Если модель не может обработать текст или уверенность ниже порога, система сообщает, что требуется ручная проверка.

**Результат:** данные резюме структурированы и доступны для дальнейшего поиска, фильтрации, оценки соответствия вакансии и экспорта; либо резюме передано на ручную проверку.
