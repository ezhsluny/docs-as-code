# Анализатор резюме

## Описание проекта

Сервис автоматически извлекает навыки, образование и опыт из резюме.

**Основные пользователи:**

- HR-специалист / рекрутер;
- нанимающий менеджер;
- соискатель;
- администратор сервиса.

**Основные функции:**

- извлечение данных (навыки, образование, опыт) на основе NLP/NER;
- оценка соответствия резюме вакансии;
- ранжирование кандидатов по релевантности;
- экспорт результатов.

## Комплект документации

1. Описание проекта — для заказчика, команды и новых участников, чтобы единообразно понимать цели, границы и ценность проекта.
2. Требования — для аналитиков, разработчиков и тестировщиков, чтобы зафиксировать функциональность, ограничения и критерии приёмки.
3. Архитектура системы — для разработчиков, чтобы понимать состав компонентов, потоки данных и интеграции.
4. Документация API — для фронтенд- и бэкенд-разработчиков, чтобы корректно вызывать сервис и обрабатывать ответы.
5. Документация ML-модели — для ML-инженеров, чтобы понимать подход, данные, метрики, ограничения и порядок дообучения.
6. Руководство пользователя — для HR-специалистов и рекрутеров, чтобы эффективно загружать резюме, анализировать результаты и работать с кандидатами.
7. Документация по безопасности и обработке персональных данных — для владельцев данных, юристов и администраторов, чтобы соблюдать правила хранения, доступа и обезличивания резюме.
